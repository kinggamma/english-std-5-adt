English Pupil’s Book Standard Five

(b) Recite/sign the following poem. Then, answer the questions that follow.
Human beings are different.
Some are neat
Some are messy
Some are fun
Some are serious
Some are kind
Some are rude
Some are loud
Some are quiet
These are human traits
The bodies of human beings are different.
Some are tall
Some are short
Some are fat
Some are slim
Some are heavy
Some are light
Some are young
Some are old
But, bound by one breath, we rise in our differences.
