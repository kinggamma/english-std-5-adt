(e) Listen carefully to/observe instructions on how to set an alarm on one of the gadgets below.

1. A mobile phone
2. An alarm clock
3. A digital watch
How to set an alarmOpen the Clock app. This app usually looks like a clock icon. If it is not on the home screen, search for Clock in the app drawer.Tap the Alarm tab. This is usually the first tab at the bottom or top of the screen.Tap the “+”, or Plus, icon to create a new alarm.Set the time using the clock dial or number pad to select the hour and minutes. Choose AM or PM if applicable.Tap OK or Save. Your alarm is now set.
